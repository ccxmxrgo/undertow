UNDERTOW Autocharter pack - third-party software and licences
==============================================================

The Autocharter pack is an optional download for the game UNDERTOW. It contains a Python
runtime, unmodified third-party Python packages and native libraries, two machine-learning
model files and the UNDERTOW autocharter scripts (folder app/). This file summarises the
third-party components and their licences. The full licence texts ship next to the
components they cover; NOTICES/INDEX.txt lists every licence file in this pack.

The pack contains no audio files (no music, no samples). Charts are made from audio the
player chooses on their own computer.

Every third-party component is redistributed unmodified, in the form its upstream project
publishes (python-build-standalone archive, PyPI / download.pytorch.org wheels, model files
from the upstream projects).
