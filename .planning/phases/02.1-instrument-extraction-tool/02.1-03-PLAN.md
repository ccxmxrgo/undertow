<interfaces>
Note record contract (defined in plan 02-02 interfaces; plan 02 and 03 run in parallel, so it is repeated here exactly): dict with "tick" (int), "t" (float s), "t_onset", "strength" (float), "pitch" (float MIDI or None), "amp" (float or None), "centroid" (float Hz or None), "end_tick" (int or None), "snap", "src", "lanes" (list[int]), "len" (int ticks). This plan adds "base_lane" (int, the contour lane before any accent chord).

TempoMap dict keys used here: "resolution" (192), "bar_ticks" (list of bar start ticks), "beat_ticks". Beats sit on multiples of 192 ticks (tempo_map places every beat at k * 192), so tick % 96 == 0 means "on the 1/8 grid" and tick % 192 == 0 means "on a beat". Tests build a TempoMap dict literal with these keys; do not import tempo_map.py.

Reference targets (SPEC Neversoft table): Hard keep 90-100% of Expert ticks, <= 7 notes/s in any 1 s, about half of Expert chords become single notes; Medium keep 65-75%, 1/8 grid, <= 3% chords (2-note, strongest downbeat accents), <= 5/s; Easy keep 45-55%, lanes 0..2, no chords, <= 4/s, sustains kept; lane steps repeat 20-30 / +-1 40-60 / +-2 15-30 / +-3 <= 5 %.

Research contour reference (build/research/scripts/contour.py `lanes()`): start lane 1, step 0 / +-1 / +-2 (|d| >= 5), plain clamp. ORCHESTRATOR DECISION (replaces the plain clamp): VISIBLE SLIDE. A clamped step is a step whose target lane would leave 0..n_lanes-1; the lane stays at the edge and a per-direction counter increments. When the counter is already >= 2 and the next step goes the same direction, the window shifts: that note goes to lane 1 (rising) or lane n_lanes-2 = 2 (falling, 4 lanes) and the counter resets; later steps continue from there. A step in the opposite direction resets the counter; repeats (step 0) and unpitched notes do not change it. Pitch per note is the Basic Pitch skyline (plan 04).
