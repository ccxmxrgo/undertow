## How to test

1. Unzip `build/dist/UNDERTOW-playtest-v0.4.zip` into a new folder and start `undertow-debug.exe`
   (or run the project from the editor).
2. In SELECT SONG, check that all 5 bundled songs are listed and each one plays a preview.
3. Play each song on **Expert**, then on **Easy**. For each one, answer the two questions:
   - **Is there a sound under every note?**
   - **Does going right feel like going up in the music?**
   Write down the song, difficulty and timestamp (e.g. `1:20`) of anything that feels off.
4. Sea Shanty 2 is the showcase. If you know the tune, the lanes should "sing" it.
5. Look at the UAT flags below and say whether each one is OK.
6. Optional: run the extract command on one of your own files (see "Optional" below).
7. Answer the open questions and the STEM-02/04 decision row.

## Optional: your own song

```
powershell -NoProfile -File tools/autochart/extract_song.ps1 -Audio "<your file.mp3>" -Name "<title>"
powershell -NoProfile -File tools/autochart/extract_song.ps1 -Audio "<your file.mp3>" -Name "<title> lanes" -Mode lanes
```

Then go to Settings > LIBRARY > Rescan and play both. In lanes mode each lane is one instrument
(bass, drums, other, vocals from left to right). About 2/3 of Expert notes may be chords, so say if
that feels too chordy.
