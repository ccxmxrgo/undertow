<interfaces>
Shared data contracts for Phase 2.1 (plans 02, 03, 05, 06, 08 all use these; do not rename keys):

Onset record (input to build_expert; produced by plan 04 stages/onsets.py): dict with "t" (float s, Godot time base), "strength" (float), optional "pitch" (float MIDI or None), "amp" (float or None, Basic Pitch amplitude), "centroid" (float Hz or None), "off_t" (float s or None, detected note end), "src" (stem name string).

Note record (output of build_expert; lanes/reduce/write use it): every onset key passed through, plus "tick" (int), "t" (float s = tick_to_sec(tm, tick)), "t_onset" (float s, original onset), "snap" ("16" | "12" | None), "end_tick" (int or None, from off_t), "lanes" (list of int, filled by plan 03 lanes.py), "len" (int ticks, sustain length, 0 = tap).

TempoMap dict: "resolution" (192), "delay_ms" (int), "events" (list of [tick, "TS", num] / [tick, "B", milli_bpm], sorted by tick, TS before B at the same tick), "beat_ticks" (list int), "beat_times" (list float s, same length), "bar_ticks" (list int, start tick of every bar).

Importer facts (src/core/chart_importer.gd): BPM clamp 1..2000 (MIN_BPM/MAX_BPM); a sustain with len * 4 <= resolution (<= 48 ticks) is a tap (SUSTAIN_TAP_DIVISOR 4); gems 0..3 map to lanes 0..3 (identity, D-05), 4 merges into lane 3, 7 = open chord -> never write 4 or 7; time of a tick = segment sec + (tick - seg_tick) / res * 60 / bpm, plus delay_ms / 1000.

Existing chart text format (songs/synth_wave_april/notes.chart): `[Song]` block with two-space indented `Name = "..."`, `Artist = "..."`, `Charter = "..."`, `Resolution = 192`, `Genre = "..."`; `[SyncTrack]` lines `  0 = TS 4`, `  0 = B 120000`; `[Events]` lines `  <tick> = E "section <Name>"`; tracks `[EasySingle]`, `[MediumSingle]`, `[HardSingle]`, `[ExpertSingle]` with `  <tick> = N <lane> <len>` and `  <tick> = E solo` / `  <tick> = E soloend`; LF line endings.
