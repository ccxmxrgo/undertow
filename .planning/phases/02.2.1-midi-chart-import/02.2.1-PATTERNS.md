Limits-override entry point (lines 22-30) — `read(bytes, limits := {})` should mirror this so tests can shrink caps (`max_tracks`, `max_entries`):
```gdscript
## limits (optional, tests): {max_bytes, max_lines, max_entries} override the caps.
static func parse_bytes(bytes: PackedByteArray, limits: Dictionary = {}) -> ParsedChart:
	var max_bytes: int = limits.get("max_bytes", MAX_BYTES)
	var max_lines: int = limits.get("max_lines", MAX_LINES)
	var max_entries: int = limits.get("max_entries", MAX_ENTRIES)
	var pc := ParsedChart.new()
	if bytes.size() > max_bytes:
		pc.error = ERR_TOO_LARGE
		return pc
```

Warn counter pattern (lines 214-217) — reuse for skipped extra tracks / orphan note-offs:
```gdscript
static func _warn(pc: ParsedChart, line: int) -> void:
	pc.warnings += 1
	if pc.first_warning_line == 0 and line > 0:
		pc.first_warning_line = line
```

**Analog B (bounded binary loop, manual big-endian):** `src/core/song_scanner.gd` `read_id3` lines 376-415
```gdscript
	var size := (int(head[6]) & 0x7F) << 21 | (int(head[7]) & 0x7F) << 14 \
			| (int(head[8]) & 0x7F) << 7 | (int(head[9]) & 0x7F)
	size = mini(size, MAX_ID3_BYTES)
	...
	while pos + hlen <= body.size():
		...
			fsize = int(body[pos + 4]) << 24 | int(body[pos + 5]) << 16 \
					| int(body[pos + 6]) << 8 | int(body[pos + 7])
		if fsize <= 0 or pos + hlen + fsize > body.size():
			break
		var data := body.slice(pos + hlen, pos + hlen + fsize)
		...
		pos += hlen + fsize
```
Key carry-overs: always `pos + n <= end` before indexing; `slice(start, end)` with end exclusive; lengths checked against remaining bytes before skipping. SmfReader must return an error (not `break`) on overrun, per RESEARCH Pattern 1 / Pitfall 1. Use RESEARCH "Code Examples" `_vlq`, `_u16`, `_u32` verbatim as the starting shape.

ASCII magic check (song_scanner.gd line 382): `head.slice(0, 3).get_string_from_ascii() != "ID3"` -> use `bytes.slice(p, p + 4).get_string_from_ascii() == "MThd"` / `"MTrk"`.

## Shared Patterns

### Untrusted-input parser contract
**Source:** `src/core/chart_parser.gd` lines 1-30, 207-217
**Apply to:** `smf_reader.gd`, `midi_chart_reader.gd`
- `static` functions only, `RefCounted`, typed locals (`var x := ...`, `var a: Array = ...`).
- Never `assert`, never `print`/`push_error` per event; failures go to `pc.error` with a fixed string; soft problems go to `pc.warnings += 1`.
- Optional `limits: Dictionary = {}` parameter on the public entry for tests.
- Caps as named `const`s at the top.

### Broken-entry error flow
**Source:** `src/core/song_scanner.gd` `_fail` lines 366-370 + `src/core/song_entry.gd` `hint_for` lines 52-75
**Apply to:** scanner, song_entry, song_library
Every error string a reader can return must be a `SongEntry.ERR_*` const with a `hint_for` arm, so the existing Song Select broken-row UI shows it with no UI change.

### Single chart-parse choke point
**Source:** new `ChartFile.parse`
**Apply to:** `song_scanner.gd:297`, `song_library.gd:209`, `song_select.gd:585`, `playtest_driver.gd:3943`
The scan fingerprint must equal the play fingerprint (`song_library.gd` lines 222-225), so all four sites must use the same parse function.

### Test fixtures generated at runtime
**Source:** `tests/helpers/song_fixture.gd` (rm_tree/mkdir/write_bytes/make_wav)
**Apply to:** all new tests. Work under `user://test_*`; never commit `.mid` charts or audio (D-10). `before_test`/`after_test` cleanup like `tests/test_song_scanner.gd` lines 9-23.
