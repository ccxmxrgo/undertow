<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SmfReader output (from untrusted .mid) -> MidiChartReader | Note pitches, ticks, tempos, SysEx payloads and text are attacker-controlled |
| MidiChartReader -> ChartImporter -> UI | Section names and solo markers reach Song Select / HUD |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.2.1-07 | Tampering | tempo uspqn 0 / huge | mitigate | Skip uspqn <= 0 with a warning (no division by zero); ChartImporter clamps BPM 1..2000 and drops non-finite note times (unchanged) |
| T-02.2.1-08 | DoS (memory) | gem/solo explosion | mitigate | Per-difficulty gem cap ChartParser.MAX_ENTRIES (300000) with warnings; unrecognised tracks never parsed (keep_names); downstream MAX_SECTIONS/MAX_TIME_SIGS caps |
| T-02.2.1-09 | Tampering | SysEx payloads | mitigate | Only exact 8-byte payloads matching 50 53 00 00 diff 01 value F7 are interpreted; diff outside 0..3/0xFF ignored |
| T-02.2.1-10 | Tampering (UI) | section text | mitigate | Only "section " + name emitted; ChartImporter._clean_section_name (unchanged) strips control chars, caps 64 chars, dedupes, caps 256 sections |
| T-02.2.1-11 | Repudiation / integrity | scan vs play divergence | mitigate | Reader is bytes-in/chart-out (never reads song.ini), so the same file always yields the same fingerprint; parity test asserts identical fingerprints |
| T-02.2.1-12 | Information disclosure | error strings | accept | Errors are fixed constants; no file content echoed; no PII involved |
</threat_model>
