SmfReader (src/core/smf_reader.gd), class_name SmfReader, extends RefCounted, static only:
```gdscript
const MAX_BYTES := 16 * 1024 * 1024
const MAX_TRACKS := 256
const MAX_ENTRIES := 300000      # per list per track (notes/texts/tempos/time_sigs/sysex); extras dropped, warnings += 1
const MAX_TEXT := 256            # bytes kept from one text/name event; rest skipped by length
const MAX_TICK := 2147483647     # same as ChartParser.MAX_TICK; absolute tick above it -> fail

## keep_names (optional): upper-cased track names to parse fully. Track index 0 is always parsed fully.
## When keep_names is non-empty, any other track whose name is not in it gets {name, index, skipped=true}
## with empty lists and the rest of its chunk is skipped by length (VENUE/drums/vocals never walked).
static func read(bytes: PackedByteArray, limits: Dictionary = {}, keep_names: PackedStringArray = PackedStringArray()) -> Dictionary
# returns:
# {
#   "ok": bool, "error": String,          # "" | SongEntry.ERR_MIDI_BAD | SongEntry.ERR_TOO_LARGE
#   "format": int, "division": int, "warnings": int,
#   "tracks": Array[Dictionary] each:
#     {"index": int, "name": String,       # first FF 03 at tick 0, strip_edges(), "" if none
#      "skipped": bool,
#      "notes": Array of {"tick": int, "pitch": int, "on": bool, "seq": int},   # 9n vel>0 -> on; 8n or 9n vel 0 -> off
#      "texts": Array of {"tick": int, "text": String, "seq": int},             # FF 01..0F except 03
#      "tempos": Array of {"tick": int, "uspqn": int, "seq": int},              # FF 51 (len >= 3)
#      "time_sigs": Array of {"tick": int, "num": int, "exp": int, "seq": int}, # FF 58 (len >= 2)
#      "sysex": Array of {"tick": int, "data": PackedByteArray, "seq": int}}    # F0/F7 payloads of length exactly 8 only
# }
# limits keys (tests): max_bytes, max_tracks, max_entries
# seq: one counter per track, incremented on every stored item, preserves file order.
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Songs folder / library folder / zip cache -> SmfReader | `.mid` bytes come from files friends download from the internet; fully untrusted |
| SmfReader result -> UI | Track names and text strings later reach the Song Select UI (via section names) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.2.1-01 | Tampering / DoS | SmfReader chunk + event reads | mitigate | Every read checks `pos + n <= chunk_end`; chunk/meta/SysEx lengths validated against the remaining bytes before skipping; fail with fixed "Unreadable .mid"; truncation sweep + fuzz test |
| T-02.2.1-02 | DoS | VLQ / tick accumulation | mitigate | VLQ capped at 4 bytes; absolute tick > 2147483647 fails |
| T-02.2.1-03 | DoS (CPU/memory) | event floods, huge files | mitigate | 16 MB MAX_BYTES before parsing; MAX_TRACKS 256; MAX_ENTRIES 300000 per list; keep_names skips unrecognised tracks by length without walking events |
| T-02.2.1-04 | DoS (hang) | parse loop | mitigate | Every iteration advances pos; fuzz test with a 5 s budget proves termination |
| T-02.2.1-05 | Information disclosure / UI tampering | error strings | mitigate | Errors are fixed constants (SongEntry.ERR_MIDI_BAD / ERR_TOO_LARGE); file bytes are never echoed |
| T-02.2.1-06 | Tampering (UI) | text events (control chars, huge, invalid UTF-8) | mitigate | Text capped at MAX_TEXT bytes; ASCII/UTF-8 decode without errors; downstream ChartImporter._clean_section_name (unchanged) strips control chars and caps to 64 chars |
| T-02.2.1-SC | Tampering | third-party parser code | mitigate | No package installs; brainfoolong/gdscript-midi-parser rejected and not vendored (RESEARCH Package Legitimacy Audit) |
</threat_model>
