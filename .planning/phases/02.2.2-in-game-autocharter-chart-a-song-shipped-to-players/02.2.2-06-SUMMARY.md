# Phase 02.2.2 Plan 06: Autocharter pack build Summary

Two builds from fresh stages gave byte-identical SHA256SUMS. The extracted pack passes its selftest. ## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Git Bash's GNU tar shadowed Windows tar.exe**
- **Found during:** Task 2, first build ("Cannot connect to C: resolve failed").
- **Fix:** the build calls `$env:SystemRoot\System32\tar.exe` (bsdtar) explicitly. Commit 6c986c6.

**2. [Rule 2 - Info disclosure] rt/Scripts embedded the build path**
- **Issue:** uv's console entry points (demucs.exe, hf.exe, ...) hold `C:\Users\User\UNDERTOW\build\pack\stage\rt\python.exe`. This leaks the user name and is useless on player PCs.
- **Fix:** `Scripts` was added to PRUNE_DIRS, with a test. Afterwards a grep found no build path anywhere in rt. Commit 6c986c6.

**3. [Rule 2 - Correctness] Mixed VC++ runtime versions**
- **Issue:** python-build-standalone ships vcruntime140/_1 14.44, and the redistributable msvcp140*/concrt140 are 14.51. The plan said "copy when not already present", which would have shipped a mixed set.
- **Fix:** all six DLLs are copied from the one installed redistributable, overwriting the older pair. The selftest and job pass with this set. Commit 6c986c6.

**4. [Rule 1 - Determinism] App files normalised to LF**
- **Fix:** the app and NOTICES copies strip CR, so the app part hash does not depend on the git autocrlf setting of the checkout that builds it. Commit 6c986c6.

**5. [Rule 1 - Test] The plan 03 test `test_spec_empty_build` asserted an empty PackSpec**
- **Fix:** it is now `test_spec_contract`. It keeps the TAG, URL and as_dict checks and compares parts and unpacked_bytes with the constants. The pinned values are checked in test_pack_spec.gd. Commit 6c986c6.

### Notes
- `build_pack.ps1` writes its smoke extractor to `build/pack/extract_parts.py`, not to an inline `-c` string, because Windows PowerShell 5.1 mangles quotes in native arguments.
- uv installs with `--link-mode copy`, so the stage never hard-links into the uv cache.
- No STATE.md or ROADMAP.md edits. default_bus_layout.tres and the plan 08 files were left alone. Nothing was uploaded or published.
