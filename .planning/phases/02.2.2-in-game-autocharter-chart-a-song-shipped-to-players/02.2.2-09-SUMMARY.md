# Phase 02.2.2 Plan 09: Chart a Song running, result and error states Summary

The Chart a Song screen now runs the whole D-01 flow. Start Charting writes job.json into a fresh job dir and launches `autochart.py job` through AutochartRunner with the fixed argv. The screen shows a 5-row stage list, an overall bar, the elapsed time and a confirmed Cancel. When the job finishes, the result shows the song, instrument and Expert density. Play Now rescans the library and opens Song Select on the new song. Chart Another Instrument goes back to the options with the next ranked instrument selected, so the cached stems are reused. A failure shows the plain reason with Try Again and Show Details. A pack whose selftest has not passed runs the selftest first. The new AutochartWorkCache keeps the stems of the last 3 songs and backs Clear Chart Cache.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The selftest would always look failed**
- **Found during:** Task 2 design (reading autochart_runner.gd against plan 05's selftest output)
- **Issue:** `autochart.py selftest` prints `{"ev":"selftest","ok":true}` and exits 0 without a `done` event. AutochartRunner maps that to `failed("internal")`.
- **Fix:** The screen records the selftest event through `event_received`. A failure signal that arrives after an ok event counts as a pass.
- **Commit:** b4aff96

**2. [Rule 3 - Blocking] A plan-08 test contradicted the plan-09 gate**
- `test_installed_signal_moves_to_pick` emitted `installed` with no marker, so `selftest_ok()` was false and the new gate ran the selftest. The test now writes a marker with selftest passed first, which matches what the real installer does.

### Additions within scope (Rule 2, threat model T-02.2.2-44..48)

- T-45/T-46: Show Details ignores a child-supplied log path unless it is a `.txt` inside the pack root. AutochartWorkCache refuses any delete outside `AutochartPaths.root()`.
- T-47: `_exit_tree` and `NOTIFICATION_WM_CLOSE_REQUEST` cancel a running child. If the screen leaves mid-run, the unfinished work dir is removed by the next `prune`.
- T-48: `_on_start_requested` checks `is_installed()` and `selftest_ok()` again before it launches anything.
- Remove Autocharter Pack and Clear Chart Cache are disabled while the child runs, and both handlers refuse too. `remove_pack` gets the real running state.
- After you confirm Stop, the footer reads "Stopping..." until the process is gone.
