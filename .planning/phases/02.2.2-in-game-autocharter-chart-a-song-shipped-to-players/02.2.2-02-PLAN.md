Event protocol (stdout, one ASCII JSON object per line; produced by the Python job in plan 05):
  {"ev":"start","pid":n}  {"ev":"work","dir":abs}  {"ev":"stage","k":k,"n":n,"name":s}
  {"ev":"progress","frac":0..1}  {"ev":"warn","msg":s}  {"ev":"rank","recommended":s,"ranking":[...]}
  {"ev":"error","code":c,"stage":s,"msg":s,"log":abs}  {"ev":"selftest","ok":true,"seconds":x}
  {"ev":"done","folder":abs,"slug":s,"stem":s,"mode":s,"expert_nps":x,"reused":bool,"ranking":[...],"log":abs}
Exit codes: 0 ok, 2 = an error event was printed (ANY code, including internal and vcredist), 3 MemoryError, 4 parent gone, other = crash. Runner rule (W1): on any non-zero exit, if an error event was received its code/message/log win; only without an error event does the exit code decide (3 memory, 4 internal unless cancelled, other crash).

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.2.2-06 | Tampering | build_args / argv | mitigate | argv holds only fixed tokens plus two paths checked by safe_path_arg (absolute, no '"', no trailing separator, no control chars); name/artist only in job.json written with JSON.stringify |
| T-02.2.2-07 | Tampering | parse_event | mitigate | JSON.parse_string per line, non-Dictionary or missing "ev" ignored; numbers clamped; unknown events ignored |
| T-02.2.2-08 | DoS | stdout/stderr pipes | mitigate | both pipes drained every frame with non-blocking get_length/get_buffer; stderr tail capped at 64 KB; partial-line buffer kept (Pitfalls 1/2) |

| T-02.2.2-10 | Elevation | start() | mitigate | interpreter path must exist; the child is launched with -I (no cwd/PYTHONPATH on sys.path) |
