| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02.2.2-45 | Tampering | done event folder | mitigate | the screen only uses result.folder for SongScanner.norm and display; the library scan still validates the folder like any other song; no file operations on that path |
| T-02.2.2-46 | Tampering | cache/cancel deletes | mitigate | AutochartWorkCache deletes only under AutochartPaths.root(); unfinished-dir removal only after the runner reports the process gone |
| T-02.2.2-47 | DoS | orphan process on screen exit / quit | mitigate | _exit_tree and WM_CLOSE_REQUEST cancel; runner kills on PREDELETE; Python stdin-EOF watchdog as backstop |
