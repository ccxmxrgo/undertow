<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub release assets -> player PC | downloaded archives that contain executable code (python.exe, DLLs) |
| player-chosen folder ("Install from Folder") -> pack root | local files of unknown origin |
| pack root on disk -> later runs | installed code reused across sessions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.2.2-11 | Tampering | downloaded/copied part | mitigate | size + SHA-256 compared to PackSpec values compiled into the game; mismatch deletes the file and nothing is extracted; the hash list never comes from the network |
| T-02.2.2-12 | Tampering | part extraction (zip-slip) | mitigate | ZipExtractor.safe_rel on every name, fail closed on any unsafe name, simplify_path prefix check against dest, extraction only into staging under AutochartPaths.root() |
| T-02.2.2-13 | DoS | decompression bomb / huge part | mitigate | body_size_limit = pinned size + 1 KiB; central-directory caps (60000 entries, 600 MiB per entry, 1.6 GiB total) checked before any write; Zip64 refused |
| T-02.2.2-14 | Tampering | partially installed pack executed | mitigate | installed.json written last; is_installed requires it plus matching hashes and rt/python.exe; staging renamed only after every part verified |
| T-02.2.2-15 | Spoofing | downgrade to HTTP / other host | mitigate | only https:// URLs built from the pinned BASE_URL; redirects are followed by HTTPRequest but content is hash-checked regardless of host |
| T-02.2.2-16 | DoS | disk exhaustion | mitigate | 2 GiB free-space check before a full install (0 = unknown -> warn), dl/ and staging deleted after install or cancel |
| T-02.2.2-17 | Tampering | recursive delete | mitigate | remover refuses any path outside AutochartPaths.root(); remove_pack refuses while a job runs |
</threat_model>
