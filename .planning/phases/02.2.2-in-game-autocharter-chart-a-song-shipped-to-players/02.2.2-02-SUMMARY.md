# Phase 02.2.2 Plan 02: Godot job protocol and process runner Summary

The game now has its half of the autocharter protocol. `AutochartJob` writes job.json, builds a fixed 7-token argv with no free text, and splits and parses JSON event lines. `AutochartRunner` starts the child, drains both pipes every frame without blocking, cancels it, kills it on quit or free, and turns failures into the 18 player-facing error texts. The pure logic is tested with a fake process.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] parse_event logged an engine ERROR for every junk line**
- **Found during:** Task 1 (GREEN run)
- **Issue:** `JSON.parse_string` prints "Parse JSON failed" for every non-JSON line. Child noise on stdout would flood the log.
- **Fix:** Lines that do not start with `{` are rejected early. Other lines are parsed with a `JSON` instance, which fails without logging.
- **Commit:** a9dcd5f

### Additions within scope (Rule 2, threat model T-02.2.2-07/08/10)

- `safe_path_arg` also rejects Godot virtual paths (`res://`, `user://`) and empty strings.
- `validate` rejects missing keys and wrong value types (for example a version mismatch or a non-bool replace), not only bad values.
- The runner drops a partial stdout line once it passes 1 MB. A run with a missing interpreter or an unsafe .py/.json argument fails with `start` before any process is launched.
