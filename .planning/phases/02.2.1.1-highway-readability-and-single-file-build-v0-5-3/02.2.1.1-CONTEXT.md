<decisions>
## Implementation Decisions

- **D-01 Wider far end:** the far (horizon) end of the highway is much wider than in v0.5.2, so the four lanes
  stay visibly apart all the way to the horizon and far notes no longer merge into one blob.
- **D-02 Fade-in, readable far notes:** notes fade in (alpha ramp) over the far end instead of popping in as
  tiny specks; the smallest drawn note size at the far end is already readable.
- **D-03 Steadier speed:** the perspective speed ratio (on-screen note speed at the hit line vs at the far end)
  drops from about 7.8x to about 2.9x. Planner/researcher measure the current ratio from the code and pick
  projection parameters that land at ~2.9x (tolerance +-0.2), proven by a unit test.
- **D-04 Calmer far end:** board lines (beat/bar lines, rails, strips), glows and sweeps fade out toward the far
  end.
- **D-05 Timing unchanged (hard rule):** a note is exactly on the hit line at its on-time moment
  (tests/test_visual_sync.gd stays green, extend it if the projection changes), the SAME number of beats is
  visible at 1x scroll speed as before, the timing gate prints TIMING GATE OK, and the timing-core files are not
  touched. Sustains, chord bars, receptors, Arena colonies keep-out and HUD keep-out tests stay green.
- **D-06 1x looks slower near the line:** accepted consequence (README says so); no scroll-speed default change.
- **D-07 Single-file build:** the friend zip contains only UNDERTOW.exe (pck embedded, `binary_format/embed_pck`),
  README.txt and TESTER-CHECKLIST.txt. dist.ps1's allow-list, the BUNDLED_OK 20 selftest (run against the
  unzipped single exe; a console wrapper may still be needed to read selftest output — researcher decides how
  the selftest runs without a separate console exe) and README "HOW TO RUN" wording follow the v0.5.3 README.
- **D-08 Effects modes:** Low effects and Reduce motion keep working; their enumeration tests stay green.
- **D-09 Friend build:** ends with a v0.5.3 zip built locally (`tools/dist.ps1`), README/checklist text taken
  from the reference v0.5.3 files (title, intro line, WHAT'S NEW IN v0.5.3, HOW TO RUN, checklist line 62-63 and
  the "Highway: easier or harder to read" big question). Push to origin main after every plan.
