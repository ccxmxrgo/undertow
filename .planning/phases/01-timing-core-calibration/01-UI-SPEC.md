# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1: Timing Core & Calibration. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Platform: Godot 4.7.2 (GDScript, Control nodes + one shared Theme resource, Compatibility renderer). Not a web app: all values are pixels at a **1920x1080 base viewport**, `stretch/mode = canvas_items`, `stretch/aspect = keep`. Mode: --auto. Items marked (default) were not decided upstream and were chosen by the researcher. Items marked (D-xx) come from 01-CONTEXT.md.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn is not applicable; Godot engine). Registry gate: not applicable |
| Preset | not applicable |
| Component library | Godot built-in Control nodes styled by ONE project Theme: `res://ui/undertow_theme.tres` (StyleBoxFlat only, no textures) |
| Icon library | none. Glyphs are drawn in code (`_draw()` polygons/circles) or as font characters. Lane shapes are drawn, not imported (D-24) |
| Font | **Share Tech Mono** (OFL, vendored in `res://assets/fonts/`) as the single UI and HUD font; fallback to Godot's default font if missing. Monospace gives the sonar-terminal feel and keeps numeric readouts from jittering (default) |
| Base viewport | 1920x1080, stretch `canvas_items`, aspect `keep`; all layouts built with anchors/containers, no absolute pixel positions outside the highway (default) |
| Renderer | Compatibility (D-04). No shader, bloom, scanline or glow in this phase (AV-01 is Phase 5, D-25) |

Theme rule: every screen uses the shared Theme. Per-node overrides only for the highway, which is drawn by code from the Palette constants below.

## Spacing Scale

Declared values (multiples of 4). Use as Theme constants (`separation`, `margin_*`, StyleBox `content_margin_*`) and as the layout grid.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon/glyph gaps, text-to-border inset in readouts |
| sm | 8px | Compact spacing, label-to-value gap, list row separation |
| md | 16px | Default Container separation, button inner padding |
| lg | 24px | Panel padding, group gaps in menus |
| xl | 32px | Gap between HUD clusters and screen edge (safe margin) |
| 2xl | 48px | Major section breaks, minimum interactive row height |
| 3xl | 64px | Screen-edge padding on full-screen menus |

Exceptions:
- Stroke widths (lane lines, hull line, borders) use 2px and 4px. Strokes are not spacing.
- Highway geometry (fixed, multiples of 4): lane width **128px**, lane gap **0px** (lanes separated by a 2px divider line), total highway width **512px**, centered horizontally. Hull line sits at **y = 880px** (200px above bottom edge); notes spawn above y = -64px (off-screen).
- Note glyph size: 80px bounding box, centered in lane. Hit-lane flash: full lane width, 160px tall above the hull line.
- Minimum interactive control height: 48px (2xl). Minimum focusable list row: 48px.
- All HUD content stays inside a 32px safe margin (xl).

---

## Typography

Font: Share Tech Mono. Exactly 4 sizes and 2 weights.
Weights: **Regular (400)** and **Bold (600-equivalent)**. Share Tech Mono ships one weight, so Bold is produced with `FontVariation` (`variation_embolden = 0.5`) as a single shared resource.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label (HUD captions, hints, ms offsets, debug text, button hints) | 20px | Regular | 1.5 |
| Body (menu items, settings rows, buttons, dialog text, floating judgment text) | 28px | Regular (Bold for buttons, selected item, and floating judgment text) | 1.5 |
| Heading (screen titles, HUD values: depth, combo, multiplier, streak) | 40px | Bold | 1.2 |
| Display (IMPLOSION, countdown numerals 3-2-1, calibration offset result) | 96px | Bold | 1.2 |

Rules:
- Heading and Display text is UPPERCASE with letter spacing +2px (via `FontVariation.spacing_glyph = 2`). Body and Label stay as written.
- The F3 debug overlay (D-29) uses Label size only and is exempt from copy rules.
- Numerals always monospaced; HUD values right-aligned in fixed-width boxes (min 8 characters) to avoid layout shift.

## Color

Phosphor-on-black sonar palette (D-24). Defined once as constants in `res://ui/palette.gd`; the Theme and highway both read them.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#000000` | Screen background, highway background, pause/dialog dim base |
| Secondary (30%) | `#0A1F0A` fill, `#1F8F0C` dim-green lines/borders, `#8FD98A` secondary text | Panels, menu rows, hull bar track, lane dividers, inactive text and borders |
| Accent (10%) | `#39FF14` | Reserved list below |
| Destructive | `#FF4A3D` | Destructive/critical states only (below) |

Accent reserved for (never "all interactive elements"):
1. The hull line (horizontal strike line) and active lane flashes
2. Notes and sustain tails (outline/fill; shape is the primary differentiator)
3. Hull bar fill while hull is above 30
4. The focused menu item / focused button border and caret (the single focus indicator)
5. PERFECT floating text and the Perfect streak value
6. Large Display values (countdown numerals, calibration result)

Non-accent text defaults to `#8FD98A` (body) with `#39FF14` only for item 4-6 above.

Destructive `#FF4A3D` reserved for:
1. Hull bar fill at hull 30 or below, and the hull bar damage flash
2. MISS floating text
3. IMPLOSION title and screen
4. Quit-to-menu / Restart confirmation emphasis, and rebind conflict error text
5. Bluetooth latency warning text in the calibration wizard

Other judgment colors: GOOD floating text uses `#8FD98A` (secondary text color), not a new hue. Do not introduce further colors.

Contrast: `#39FF14`, `#8FD98A` and `#FF4A3D` on `#000000` all exceed 4.5:1 (checked: approx. 14:1, 11:1, 6:1).

Color is never the sole signal (D-22): every state pairs color with shape and/or text (see Highway and Feedback).

## Layout and Screen Inventory

Screens in scope for Phase 1. All are Control scenes sharing the Theme. All screens fully operable by keyboard and gamepad (no mouse requirement; mouse works as a bonus).

| Screen | Purpose | Requirement |
|--------|---------|-------------|
| Boot / Main menu (minimal) | Entry: Play Test Song, Calibrate, Settings, Quit. First launch routes to Calibration (skippable) | CAL-01, D-16 |
| Calibration wizard | Audio offset, visual offset, latency info | CAL-01, D-16, D-17 |
| Gameplay (highway + HUD) | The playable solo screen | TIME-*, HULL-* |
| Pause menu (overlay) | Resume Dive, Restart Dive, Settings, Back to Menu | HULL-04, D-26 |
| Resume countdown (overlay) | 3-beat 3-2-1 before audio restarts | D-26 |
| Fail screen "IMPLOSION" | Retry / Back | HULL-02, D-15 |
| Results (minimal, end of song) | Depth, max combo, Perfect/Good/Miss counts, flag if No-Fail used | D-15 (default) |
| Settings | Controls rebind, scroll speed, volume, early/late indicator, No-Fail, re-run calibration | CAL-02..04 |
| Debug overlay (F3) | Dev tooling, not player-facing | D-29 |

### Gameplay layout (1920x1080)

- Background solid `#000000`. Highway: 4 lanes x 128px = 512px wide, centered (x from 704 to 1216). Lane dividers 2px `#1F8F0C`; outer edges 2px `#39FF14`.
- Notes scroll top to bottom to the hull line at y = 880. Hull line: 4px `#39FF14`, spans highway width plus 32px each side.
- Lane label under the hull line (y = 904, Label size, `#8FD98A`): the currently bound key/button name for each lane (e.g. "D", "F", "J", "K" or "LB", "LT", "RT", "RB"). Updates when rebound.
- Note shapes, one per lane, 80px bounding box, 4px outline in accent with 25% accent fill (shape carries identity, D-24):
  - Lane 1: diamond (◆)
  - Lane 2: circle (●)
  - Lane 3: up-pointing triangle (▲, per D-24), drawn identically for all notes in the lane
  - Lane 4: square (■)
  - Phase 3 Ghost Notes will use a distinct fifth shape; leave shape drawing in a `NoteShape` helper keyed by an enum so a fifth shape can be added.
- Sustain: a 32px-wide vertical bar (accent at 50% alpha, 2px accent edge) from the head to the tail position, with a flat cap at the tail. While held, the bar brightens to full accent and the portion below the hull line is consumed.
- Chords: simultaneous notes in multiple lanes at the same y, no extra connector (each judged independently, D-09).
- HUD (all inside 32px safe margin):
  - Left column (x = 32): **Hull bar** vertical or horizontal; use horizontal 480x24px at top-left (x = 32, y = 32), track `#0A1F0A` with 2px `#1F8F0C` border, fill per Color section. Caption "HULL" (Label) above it, value "100%" (Heading) beside it. Hull bar shows a text tick at 30% as a notch mark (shape cue for the critical zone) and the caption turns "HULL CRITICAL" at 30 or below.
  - Right column (right-aligned at x = 1888): **DEPTH** (Heading value in meters, e.g. "1,240 M", with Label caption "DEPTH"), below it **COMBO** (value), **x2 MULTIPLIER** (value, e.g. "x3"), **PERFECT STREAK** (value). Rows separated by md (16px).
  - Combo/multiplier/streak values use Heading; captions use Label. Updating values pulse scale 1.0 to 1.1 over 80 ms (ease-out) on change; no pulse for depth.
  - Early/late indicator (when enabled, D-23): Label-size text directly above the hull line center, e.g. "EARLY 12 MS" / "LATE 8 MS", plus a ◄ / ► arrow glyph (shape cue). Text and arrow use `#8FD98A` (secondary text; no new hue). Fades out after 400 ms.
- No-Fail active: persistent Label "NO-FAIL" with outlined box under the hull bar in `#8FD98A`.

## Focal Point

The hull line and the approaching notes are the primary focal point: they carry the brightest accent (`#39FF14`) and the largest shapes. The HUD (hull, depth, combo, multiplier, streak) is deliberately dimmer: captions and values use secondary green `#8FD98A` by default, with accent only for the reserved uses listed in Color (PERFECT text, Perfect streak value, focus).

## Interaction Contract

### Input and focus
- Menu navigation: Up/Down/Left/Right (arrow keys and gamepad D-pad/left stick) via Godot `ui_*` actions; confirm = Enter / A; back = Esc / B. Gameplay actions (lanes, Fire, Target-cycle, Pause) never reuse `ui_*` navigation actions. Tab is never bound (D-18).
- Focus indicator (single, consistent): 4px `#39FF14` border plus a "▶" caret glyph at the left of the item. Unfocused interactive rows: 2px `#1F8F0C` border. Never rely on color alone: the caret provides the non-color cue.
- Every screen must have an initial focused control set in code on show.
- Hit-reaction latency budget: lane flash begins on the same frame the `_input()` event is judged (target: visual response next rendered frame).

### Feedback (D-22, D-23)
| Judgment | Lane flash at hull line | Floating text | Shape/other cue | Audio | Other |
|----------|-------------------------|---------------|-----------------|-------|-------|
| PERFECT | Full-lane accent flash, 120 ms fade, plus expanding ring (circle outline, 80px to 160px) | "PERFECT" Body Bold, accent | Ring + text | Subtle hit tick (SFX bus, mutable) | Hull +1 regen visible as brief bar nudge |
| GOOD | Half-brightness lane flash, 120 ms, no ring | "GOOD" Body Bold, `#8FD98A` | Text only, no ring | Subtle hit tick, slightly lower pitch | none |
| MISS | Lane flashes destructive for 160 ms with an "X" glyph (two crossing 4px lines) at the note position | "MISS" Body Bold, `#FF4A3D` | X glyph + text | Dull clunk | Screen nudge: whole gameplay root offsets 8px for 100 ms then returns; no shake persistence; respects a "Reduce screen shake" toggle (default off) |
| Stray press (no note) | Dim lane flash (25% accent), 80 ms | none | none | none | Breaks Perfect streak and combo; no hull damage (D-10) |
- Floating text: spawns at hull line y minus 48px, centered over the lane, rises 48px over 500 ms while fading out. Maximum 6 simultaneous; oldest recycled.
- Sustain feedback: while held, per-tick pop of "+10" is NOT shown (avoid clutter); the sustain bar brightens and a thin accent glow rides the hull line segment of that lane. Early release: bar dims to 25% alpha, no text, no penalty (D-11).
- Hull damage: on Miss the hull bar flashes `#FF4A3D` for 200 ms and shrinks with a 150 ms ease-out.
- Multiplier step-up: "x2/x3/x4" value flashes with a 1.1x scale pulse, no extra text.

### Countdown and pause (D-07, D-26)
- Pre-roll (start of song): 2-beat lead-in shown as two beat pips ("●  ●") above the highway center that blink on each beat; no numerals.
- Pause: Esc / Start opens an overlay (dim `#000000` at 70% alpha over the paused highway). Menu items in order: Resume Dive, Restart Dive, Settings, Back to Menu. Initial focus: Resume Dive.
- Resume: 3-beat countdown at the current song BPM, Display-size numerals "3", "2", "1", each scaling 1.2 to 1.0 in 150 ms and fading, accent color. Gameplay input for notes is ignored until the countdown completes; Esc during countdown is ignored.
- Back to Menu from pause: confirmation dialog (see Copywriting). Restart: confirmation only if score is above 0.

### Fail screen (D-15)
- Hull 0: song audio stops immediately; the highway collapses with a 400 ms vertical squash to the hull line (respect "Reduce screen shake" by cross-fading instead), then the IMPLOSION panel fades in over 300 ms. Display-size "IMPLOSION" in `#FF4A3D`. Actions: Retry Dive (initial focus), Back to Menu. Shows depth reached.

### Results (end of song)
- Panel with Heading "SURFACED" is NOT used; use "DIVE COMPLETE". Rows (Body): Depth, Max combo, Perfect, Good, Miss, Final hull. Flag row "NO-FAIL USED" if applicable. Actions: Retry Dive (initial focus), Back to Menu.

### Calibration wizard (D-16, D-17)
Flow: Intro, Audio offset test, Visual offset test, Summary. A "Skip for now" button is available on every step (initial first-launch flow is forced to open but skippable). Steps list indicator at top: "1 AUDIO  2 VISUAL  3 DONE" (current step in accent with caret, others `#8FD98A`).
- Info panel (always visible, Label size, secondary text): "Output latency: {n} ms", "Buffer: {n} ms", "Output device: {name}".
- Bluetooth warning (D-17): inline panel with 4px `#FF4A3D` left border and a "!" glyph, text per Copywriting. Does not block progress.
- Audio offset test: 16 metronome clicks at 100 BPM. Large pulsing ring in the center, drawn `#39FF14` (circle that contracts to a dot on each click, shape cue for the beat) so a player can tap along visually if audio is delayed. Tap = lane 1 key, Space, Enter, A button, or mouse click (default). Progress shown as "TAP 7 / 16". First 4 taps are not counted; show "WARM-UP" caption during them and "RECORDING" after. Result is median of the remaining taps; display result in Display size as "+42 MS" with sign. Buttons: Accept Offset, Retry Test.
- Visual offset test: a note glyph crosses a hull line in time with a click; a horizontal slider (full-width, 48px tall) adjusts offset. When the slider is focused, Left/Right (keyboard or gamepad D-pad) adjusts by 1 ms per press, and holding Left/Right (after 400 ms) repeats at ±10 ms per step. Lane buttons (including LB/RB) are not used for the slider. Current value shown in Heading ("VISUAL OFFSET +16 MS"). Slider UI range is ±200 ms; the stored value is clamped to ±500 ms. Buttons: Accept Offset, Retry Test.
- Summary: shows both offsets in Heading; buttons: Save and Continue (initial focus), Redo.
- Saved immediately to `user://settings.cfg` on Accept Offset / Save and Continue.

### Settings screen (D-18..D-21, D-23)
Sections stacked vertically as a scrollable list, each row min 48px, section headings in Heading size:
1. **Controls**: table of 7 actions (Lane 1, Lane 2, Lane 3, Lane 4, Fire, Target, Pause) with two columns: KEYBOARD and GAMEPAD. Each cell is a button showing the current binding name; activating it enters "listening" state with the label "PRESS A KEY..." (or "PRESS A BUTTON..."), accent border pulse. Esc cancels listening and leaves the binding unchanged (gamepad: B cancels). Pause can be rebound to another key and restored to Esc at any time via "Reset Controls"; Start remains the default gamepad Pause button. Listening accepts the next key or gamepad button press (mouse clicks are not accepted as bindings). Fire and Target rows carry a Label note "(Not active yet)" in secondary text. "Reset Controls" button at the bottom of the section.
   - Duplicate within the gameplay set is rejected: the binding is not applied, an inline destructive-color message appears under the row (copy below) and clears after 3 s or on next input. A "!" glyph accompanies it.
   - Only Tab is reserved (collides with `ui_focus_next`); the rebinder refuses it. Esc cannot be captured as a new binding because it cancels listening; it is restored only via "Reset Controls".
2. **Gameplay**: Scroll speed slider 0.5x to 3.0x, step 0.1, default 1.0x, value shown right ("1.0x"). Early/late indicator toggle (Settings default: ON; forced on during calibration regardless). No-Fail toggle. Reduce screen shake toggle (default).
3. **Audio**: Master, Music, SFX sliders 0 to 100%, step 5, with percentage value shown. Moving a slider plays a short SFX sample once on release (SFX and Master only).
4. **Calibration**: current audio and visual offsets shown; "Re-run Calibration" button.
- Back (Esc / B) returns to caller (main menu or pause overlay). Changes apply live and save on exit.
- Slider: 24px tall track, 32x48 handle, focus uses the standard focus indicator, Left/Right changes value by one step, hold repeats after 400 ms at 10 Hz.
- Toggle: rendered as a text pair "[ ON ]" / "[ OFF ]" in Body (so state is readable without color).

### Debug overlay (D-29)
- F3 toggles. Label size, `#8FD98A` on `#000000` at 70% alpha panel anchored top-center under the safe margin, so it doesn't overlap the HUD. Contents: song_time, raw playback position, time_since_last_mix, output latency, offsets, fps; line graph (width 320px, height 96px) of song_time per frame in `#39FF14`; last 20 hit errors in ms as a list. Not shown in release builds by default.

### Motion and reduced-motion
- All animations are short (80-500 ms) ease-out. A single `reduce_motion` setting (default off, exposed through the existing "Reduce screen shake" toggle) disables the screen nudge, the IMPLOSION squash, and number pulses.
- No flashing faster than 3 Hz over large areas: lane flash is per-lane only.
