  <behavior>
    DownbeatScheduler. The tests simulate frames: song_t advances by 1/60 s, with latency 0.02, offset 0.01 and to_next_mix 0.005. Each step calls tick().
    - 4/4 at 120 bpm over 0..20 s: fired_count == number of bars with time in [0, 20 - lead) = 10 (bars at 0, 2, 4 ... 18). Each returned from_position is in [0, lead]. Recompute the onset as (now_head + (lead - from_position)) and assert it is within 1 ms of a bar time.
    - 7/8 (time_sigs [{time 0, num 7, den 8}]) at 120 bpm: bars every 1.75 s, and the count matches.
    - A tempo change (120 -> 90 bpm at 8 s): the bar times follow BeatClock, with no double and no missing bar at the change.
    - A negative start (song_t from -3 s, the count-in): no ping for bars before time 0, and the bar at 0 pings once.
    - Late skip: one frame jumps 0.2 s past a bar, so r < -LATE_SKIP_SEC. tick returns -1 for that bar, the bar is skipped (not pinged late), and the next bar still pings.
    - Pause/resume: hold song_t constant for 60 frames (tick is not called while paused; the node guards that), then reset(song_t, ...) and continue. No bar pings twice and no bar is lost after the resume point.
    - every_n_bars = 2 pings bars 0, 2, 4 ... (by bar ordinal from the chart start, so it is stable across reset).
    - An empty tempo_map means 120 bpm 4/4 (BeatClock default) and still works. Non-finite song_t returns -1.
    HullAudioCurve:
    - cutoff_for_hull: hull >= 75 gives 20000. hull 0 gives 1500 (±0.5). The curve decreases monotonically from 75 to 0. hull 37.5 gives exp(lerp(log 1500, log 20000, 0.5)) (±1 Hz). Inputs are clamped to 0..100.
    - muffle_active(74.9) is true and muffle_active(75) is false.
    - smooth_cutoff moves toward the target in log space: after dt = tau it has covered about 63.2% of the log distance (±1%). dt = 0 means no change. It never overshoots.
    - creak_interval_for_hull: INF at 60 and above, 12 s at 59.999 (approximately), 3 s at hull 10 and below, linear in between.
    - creak_db_for_hull: -24 at 60, -12 at 10 and below, linear in between.
    - damage_creak_chance: 0 at 70 and above, 1.0 at 30 and below, linear in between.
    CreakDirector (seed 7, variants 4):
    - on_hull_changed with delta >= 0, or with hull >= 70, returns {}.
    - At hull 25 with delta -5, it always returns a creak with variant in 0..3, pitch in [0.85, 1.15] and db == creak_db_for_hull(25) + 3 (damage creaks are a little louder).
    - Cooldown: a second damage event within 0.8 s song time returns {}.
    - tick at hull 80 never creaks. tick at hull 20, called every 1/60 s for 120 s, gives a creak count within ±40% of 120 / creak_interval_for_hull(20). Gaps between creaks are never below COOLDOWN_SEC.
    - Determinism: two directors with the same seed and the same call sequence give identical outputs. A different seed gives a different sequence.

  <implementation>
- **DownbeatScheduler** keeps a small Array of upcoming bar times, refilled from `BeatClock.beats_between(from, from + WINDOW_SEC, tempo_map, time_sigs)` filtered to `bar == true` and time >= 0.
  - Track a bar ordinal (index of the bar among bar starts at time >= 0) so every_n_bars stays stable across refills and resets. On construction and on reset, compute it once by counting the bar entries of beats_between(0, t, ...); after that, increment it for every bar advanced.
  - tick: `head = song_t + latency + offset + to_next_mix`, `r = next_bar - head`.
    - If r < -LATE_SKIP_SEC: advance one bar, return -1.0.
    - If r < lead: advance one bar. If that bar's ordinal % every_n_bars == 0, increment fired and return clampf(lead - r, 0, lead). Otherwise return -1.0.
    - Else return -1.0.
    - At most one bar per tick call. A second late bar is handled on the next frame, which still never double-pings.
  - reset sets the next bar to the first bar with time >= head - LATE_SKIP_SEC that has not been fired (keep the last fired bar time and skip anything <= it).
  - Document the head formula, with a pointer to conductor.gd:163 (read-only reference; the pinned file is never edited).
- **HullAudioCurve:** static functions exactly as in the research example. The log-space smoothing is `exp(lerp(log(cur), log(tgt), 1 - exp(-dt / tau)))`.
- **CreakDirector:**
  - Uses a RandomNumberGenerator with `seed = seed`.
  - Ambient: schedule the next creak time as last + interval * randf_range(0.6, 1.4). Recompute when the interval changes by more than 20%.
  - Damage: roll randf() < damage_creak_chance(hull). Both paths respect COOLDOWN_SEC on song time.
  - Pitch is randf_range(0.85, 1.15). The variant comes from randi_range, avoiding an immediate repeat of the last variant when variants > 1.
  - Every value comes from the RNG in a fixed call order, so the output is deterministic.
