**tools/check_exe.ps1** (new). Params: `[string]$Exe = "build/UNDERTOW.exe"`, `[switch]$Selftest`, `[switch]$SkipIcon`. It resolves paths from the repo root like dist.ps1.
1. Read config/version from project.godot (same regex as dist.ps1). Expected = "<ver>.0".
2. `(Get-Item $Exe).VersionInfo`:
   - FileVersion and ProductVersion are normalised: split on '.', ',' or space, trimmed, joined with '.', and missing parts padded with 0 to 4 parts. Both must equal the expected value.
   - ProductName must be "UNDERTOW".
   - Print "EXE VERSION OK <ver>". On mismatch, Write-Error with the actual vs expected values and exit 1.
3. Icon (unless -SkipIcon):
   - Add-Type System.Drawing. Extract `[System.Drawing.Icon]::ExtractAssociatedIcon` for the exe and for the template `$env:APPDATA\Godot\export_templates\4.7.2.stable\windows_debug_x86_64.exe`.
   - Convert both to Bitmap and save each as PNG to a MemoryStream. SHA256 both.
   - Equal hashes mean "exe still has the Godot icon": exit 1. A missing template: Write-Error and exit 1 (never pass silently).
   - Print "EXE ICON OK".
4. -Selftest: run the exe `--headless -- --selftest-bundled` with the same Start-Process / handle / 120 s timeout pattern dist.ps1 uses. Require exit 0 and "BUNDLED_OK 20". Print the line.
5. Finish with "EXE CHECK OK".
