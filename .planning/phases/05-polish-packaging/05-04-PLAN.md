_ready:
- `var bank := AudioSynth.sfx_bank()` (built once per process).
- 2 ping players and 2 creak players on &"SFX" (Master fallback, like VersusSfx), round robin.
- Install the LPF per the research example:
  - Remove every existing AudioEffectLowPassFilter on Music, highest index first.
  - `cutoff_hz = OPEN_HZ`, `db = AudioEffectFilter.FILTER_12DB`, resonance 0.5.
  - add_bus_effect, then disable it.

_exit_tree: find the index i where `AudioServer.get_bus_effect(bus, i) == _lpf` (search by instance, so shifted indices do not matter) and remove it. Missing bus or effect is a no-op.

step:
1. **Muffle:** if Settings.hull_sounds is off, disable the effect and set the cutoff to OPEN. Otherwise:
   - target = FLOOR_HZ if slammed, else cutoff_for_hull(hull).
   - tau = SLAM_SEC / 3.0 if slammed, else SMOOTH_TAU.
   - cur = smooth_cutoff(cur, target, dt, tau).
   - Write `_lpf.cutoff_hz` only when it changed by more than 0.5%.
   - Enabled while muffle_active(hull) or slammed or cur < OPEN_HZ * 0.98.
2. **Pings:** only when live, not paused, Settings.sonar_pings on, song_t finite and song_t <= song_len.
   - If `_needs_reset`, call scheduler.reset(song_t, latency, offset, to_next_mix) and clear the flag.
   - `var from := scheduler.tick(...)`. If from >= 0, play the sonar_ping on the next ping player with `play(from)` and increment the count.
3. **Ambient creaks:** when live, Settings.hull_sounds on and not paused: `var c := director.tick(hull, song_t)`. A non-empty result plays creak `c.variant` with volume_db = c.db and pitch_scale = c.pitch.

_on_hull_changed(value, delta): set hull = value. If live and hull_sounds on, call `director.on_hull_changed(value, delta, _last_song_t)` and play the result.

Performance: no allocations per frame beyond the scheduler's 4 s refill, and no AudioServer writes except the throttled cutoff.
