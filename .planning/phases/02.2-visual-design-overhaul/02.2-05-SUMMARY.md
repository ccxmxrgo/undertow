# Phase 2.2 Plan 05: Component kit, effect contract, FocusMarker and UiIcons Summary

UiKit now has the full shared component kit: buttons with icons and primary/destructive variants (press squash 0.98 for 80 ms, skipped under Reduce motion), five chip variants, corner brackets, one cached radial glow texture, one cached additive material, fixed-width numeral boxes and a pop_in helper. One effect-settings contract (`FX_GROUP` plus `register_fx`) now covers every effect node, and it does not leak signals. FocusMarker draws the SONAR bar and caret. It glides between controls over 120 ms and its glow breathes from 20% to 32%. Under Reduce motion it jumps and holds a static 28%. UiIcons draws the 7 menu icons, a check and two chevrons using only polygons and 2 px strokes.

## Deviations from Plan

1. **[Rule 3 - Blocking] UiIcons moved from Task 2 into Task 1.** `make_button` draws its icon through `UiIcons.draw`, so `ui_kit.gd` would not parse without the class. The UiIcons test went into the Task 1 RED commit. Task 2 then covered only FocusMarker. Both tasks still have a RED commit followed by a GREEN commit.
2. **[Rule 1 - Test] Tween tests step by hand.** The first pop_in test sampled scale with `await_millis`, but headless frame timing caught the tween at its tail (peak was read as 1.0046). The pop_in and press-squash tests now pause the tween and call `Tween.custom_step`. FocusMarker exposes `advance(delta)` for the same reason. This keeps the tests deterministic and avoids adding another frame-rate-dependent check.
3. **[Rule 1 - Test] The breathing test now focuses a control first.** A marker with no target is hidden and does not animate.
4. **Additions beyond the plan's API:** `UiKit.reduce_motion()`, `icon_color()`, `press_squash()`, `bracket_points()`, `chamfer_points()`, `chip_style()`, `chip_width()`, `chip_font()`, and on FocusMarker `bar_rect()`, `caret_points()`, `marker_color()`, `target()` and `advance()`. These are small public helpers that make the behaviour testable and reusable for later screens.
5. **Not done (not in this plan's behaviour list):** the primary-button key hint ("right-aligned 24 px inset", UI-SPEC 4.2). The screen plans that show key hints should add it.

## Notes for later plans

- Effect nodes call `UiKit.register_fx(self)` in `_ready` and implement `apply_effect_settings()` and `effect_counts() -> Dictionary`. Tests can enumerate them with `get_tree().get_nodes_in_group(UiKit.FX_GROUP)`.
- To use FocusMarker, add `FocusMarker.new()` as a child of the screen root. It follows only controls under that parent. It is top_level, so it does not need a container slot.
- `make_button` styles are built once at creation time and are not live-swapped when Low effects toggles. This is the same behaviour as the cached theme.
- Bash in this environment has no `godot` on PATH. Use `"$GODOT_BIN" --headless --path . --import`.
