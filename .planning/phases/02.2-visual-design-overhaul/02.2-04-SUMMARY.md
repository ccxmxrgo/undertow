# Phase 2.2 Plan 04: Oxanium display face and token-built theme Summary

Oxanium Bold is now the display face. It is set to weight 700 through the integer `wght` tag, and a test proves the rendered weight is heavier than the axis default. The shared Theme is now generated from Palette tokens by `UiKit.build_theme()`: chamfered glass panels, five button states with a teal focus glow, and Oxanium headings. The legacy Palette aliases now point at the abyss/sonar tokens, so the menu, pause, results, IMPLOSION and confirm screens have all moved from terminal green to the sonar look in one step.

## Notes for later plans

- Regenerate the theme after any token or UiKit style change: `godot --headless --path . -s res://tools/make_theme.gd`. The sync test fails until you do. Sub-resource ids in the .tres are random, so each regeneration produces a noisy diff.
- `build_theme()` is cached per effects level. Screens get the Low variant only on their next `Palette.load_theme()` call, not live when the toggle changes.
- In the menu screenshot the hovered "Calibrate Sonar" button is the mouse hover state, not a second focus.
- Headless imports print "Unicode parsing error ... Unexpected NUL character" three times. They first appeared in the import run made before any Palette or theme change. They do not affect tests or the harness.
