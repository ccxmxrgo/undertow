# Phase 02.2 Plan 18: Difficulty tiles and preview visualizer Summary

Song Select difficulty tiles now show each chart's note count ("1,204 NOTES") and a 5-pip intensity meter based on notes per second. The preview plays on its own Preview bus, and a 30-bar spectrum visualizer driven by that bus's analyzer replaces the old 4-bar peak meter.

## What was built

### Task 1 (TDD: 25c7e38 test, 6a93a99 feat)
- Tiles are 176 x 96 at x 1080 / 1272 / 1464 / 1656, y 468..564. The painter and the click hit-test both use `tile_rect(i)`, so the whole new tile is clickable (the old hit-test stopped at y 560).
- The layout follows UI-SPEC 4.11:
  - lane glyph 24 px at (x+16, y+16)
  - name Body 28 at x+52, baseline y+38
  - note count Label 20 `TEXT_MID` at x+16, baseline y+66
  - 5 pips (24 x 8, 4 px gaps) at y+76..84, lit in the lane colour, unlit `ABYSS_500` 70%
- Tile states:
  - **Selected:** 2 px lane edge plus glow_sm, fill 22%, bold name, 24 x 4 bar at y 564..568.
  - **Available:** lane edge 60%, fill 10%.
  - **Unavailable:** `TEXT_LO` outline glyph and dim name, "-" for the count, no meter.
- `intensity()` thresholds: < 2.0 n/s gives 1, < 3.5 gives 2, < 5.0 gives 3, < 7.0 gives 4, otherwise 5. A length of 0 gives 1.
- All new colours use Palette tokens. SongListModel, scan, filter and sort code are untouched.

### Task 2 (TDD: 42f38d7 test, 64f3946 feat)
- `_preview_player.bus` is "Preview". It falls back to Music, then Master, if the bus is missing.
- Each `_process` calls `step_visualizer(delta)`:
  - It gets the `AudioEffectSpectrumAnalyzerInstance` once per frame and reads 30 log-spaced bands (60 Hz..12 kHz). Each level is (dB + 60) / 60, clamped to 0..1, then smoothed.
  - When no preview is playing it makes no analyzer queries and the levels fall to 0.
  - Under Reduce motion the bars sit static at 0.5 while the preview plays. Low effects keeps the animation.
- Bars are drawn at x 1080 + 24i, width 20, bottom y 816, max height 56, in `SONAR` with 2 px `SONAR_PALE` tips. With no preview, a flat 2 px `TEXT_LO` 35% line is drawn instead.
- SongSelect calls `UiKit.register_fx(self)` and implements `apply_effect_settings()` and `effect_counts()` (`visualizer_animated`, `sweep`).
- Tests: 12 new cases in tests/test_song_select.gd (43 total):
  - intensity thresholds
  - tile geometry, the new hit-test and an unavailable-tile click
  - debug_state tiles, including for a broken song
  - the Preview bus and the log band edges
  - the zero state with no analyzer calls
  - attack and release smoothing through the seam
  - Reduce motion static bars, Low keeping the animation, and the FX_GROUP contract
