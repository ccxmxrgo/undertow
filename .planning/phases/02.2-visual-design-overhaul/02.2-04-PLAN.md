## Phase Goal

**As a** player diving with friends, **I want to** every screen to look like one finished deep-sea cockpit game, with a rich board and instrument HUD that react to my hits and the music, **so that** UNDERTOW stops feeling like "a road and some numbers" while timing stays exactly as tight.

<objective>
Slice 1a, the design system (VIS-01, D-01, D-03, D-21): the Oxanium display face, the theme rebuilt from tokens, the shared UiKit components (glass panel, buttons in 5 states + primary/destructive, chips, brackets, glow texture, focus marker, fixed numeral box) and UiIcons. The legacy Palette aliases flip to the new tokens, so every theme-driven screen turns from terminal green to the abyss/sonar look in one step (visible win).

Output: fonts + licences, UiKit, UiIcons, FocusMarker, regenerated theme, tests.
</objective>
