# Phase 2.2 frame-time log (D-06 / D-17)

**Method** (harness scenario `perf`, `tools/playtest/run_all.ps1 -Scenarios perf`):

- Capture window forced to a 1920x1080 render (B1). On a 1920x1080 screen this is the game's default
  borderless `WINDOW_MODE_FULLSCREEN`; a hand-made borderless window covering the screen gets promoted
  to exclusive fullscreen, where vsync cannot be turned off, so it is not used. Other screens get a
  1920x1080 window.
- For the capture only: vsync off (`VSYNC_DISABLED`) and `Engine.max_fps = 0`, both restored afterwards.
- Per-frame `Time.get_ticks_usec()` deltas from a process_priority 1000 probe node, plus the root
  viewport's measured render CPU / GPU time.
- 30 s densest Expert window: the 30 s with the most notes over the 5 bundled songs, among windows
  that start in the first 60 s (Conductor has no seek and is timing core, so the run waits for it).
  Autoplay dive. Full effects first, then Low effects on a restarted run, same window.
- Gate: p95 <= 4.35 ms uncapped, meaning the build can sustain >= 230 fps. Refresh rate is logged only.
  When the screen is >= 239 Hz, the scenario also records a 5 s vsync-on average fps (`vsync_avg_fps`).

Plan 24 notes:
- Plan 24 was executed in a Linux cloud container with no GPU. The scenario ran under xvfb with
  Mesa llvmpipe (CPU rasterizer, about 20 fps), so its frame times measure the CPU rasterizer,
  not the game. They are logged above for completeness only. They are **not** the gate result,
  and no UI-SPEC 12 cut step was applied because of them: cutting effects to satisfy a software
  rasterizer would remove features that a real GPU renders in well under 1 ms.
- The "capture window is 1920x1080" check also failed there: window 1600x900, mode FULLSCREEN, no
  window manager. This is an environment item.
- **Remaining for the user's PC (Windows 11, RX 6600 XT, 240 Hz):** run
  `tools/playtest/run_all.ps1 -Scenarios perf`. Then fill the PENDING row with the date, commit,
  refresh rate and the Full / Low p50/p95/p99 numbers. If Full or Low p95 is above 4.35 ms, apply
  the UI-SPEC 12 cut order one step at a time and re-measure after each step:
  1. creature
  2. band fills
  3. bio glow
  4. tier rail sparks
  5. sustain sparks
  6. CRT sweep

  If it still fails after all six steps, record a FAILED GATE row (W10).
