## Phase Goal

**As a** player diving with friends, **I want to** every screen to look like one finished deep-sea cockpit game, with a rich board and instrument HUD that react to my hits and the music, **so that** UNDERTOW stops feeling like "a road and some numbers" while timing stays exactly as tight.

<objective>
Gap G3 (02.2-HUMAN-UAT.md): "The game is only playable with a controller when on a song. Menus and other stuff don't work."

Song select works only because it reads pad buttons itself.
Fix the input map, then audit and fix every screen's custom input handling, prove each screen with pad-only tests, and walk the whole flow pad-only in the harness.

Output: project.godot input overrides, pad test helper, two test files, per-screen fixes, harness scenario "pad".
</objective>
