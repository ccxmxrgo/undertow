# Phase 02.2 Plan 21: Settings and calibration restyle Summary

Settings and the Calibrate Sonar wizard now use the same design system as the menu, song select, pause and results:
- abyss table backdrop, glass panels with brackets, Oxanium headings
- pill ON/OFF toggles, restyled sliders and rebind cells
- one FocusMarker per screen
- the calibration stage shows a real lane-1 gem, the hit line and the Perfect shockwave ring

Rows, actions, the navigate seam, the click track, tap stamping and the calibration math are unchanged. "Reduce screen shake" is now "Reduce motion", and the rows have their UI-SPEC 14 hints.

## What was built

### Task 1: Settings (TDD: 25b8caa test, 51b4efb feat)
- **Background:**
  - Standalone: AbyssBackdrop "table".
  - Overlay (from pause): an ABYSS_900 85% shade and no backdrop node.
- **Header:** "SETTINGS" Heading 40 with its baseline at (64, 104), and an "ESC BACK" caption on the right.
- **Sections:** six glass PanelContainers (Controls, Gameplay, Display, Audio, Library, Calibration), each spanning x 64..1856, with brackets, a Heading 40 header and a 2 px SONAR 35% rule 16 px under the baseline.
- **Rows:** 56 px tall. The label is Body 28 TEXT_MID at x 96, the controls start at x 440, and slider values are Body 28 TEXT_HI, right-aligned to x 1840.
- **Controls table:**
  - KEYBOARD / GAMEPAD captions above the cells.
  - Rejection messages are red Label 20 lines under their row.
  - Reset Controls is a compact 48 px button.
- **Toggles:** PillToggle, 160 x 40, with chamfered corners.
  - ON: SONAR 22% fill, SONAR edge, "ON" in TEXT_HI, knob on the right.
  - OFF: ABYSS_800 fill, TEXT_LO 35% edge, "OFF" in TEXT_MID, knob on the left.
  - The knob slides over DUR_FAST (cubic out), or jumps under Reduce motion.
  - Focus adds a SONAR edge and a stroke glow (no glow on Low).
- **Rename and hints:** "Reduce screen shake" became "Reduce motion". The hints now read:
  - Reduce motion: "Turns off screen shake, parallax and big movement. Effects fade instead of moving."
  - Low effects: "Fewer particles, no glow or CRT effect, simpler backgrounds. Notes and lanes stay fully bright."
  - Menu music: "Plays a quiet song preview on the main menu."
  - Fullscreen: the F11 hint stays.
- **StepSlider:** 8 px ABYSS_600 track, SONAR fill, and a 16 x 32 chamfered TEXT_HI thumb. Focus adds a SONAR stroke glow (none on Low) and a 2 px SONAR_PALE thumb edge. The old "▶" glyph is gone (the FocusMarker draws the caret).
- **RebindCell:**
  - Listening: "PRESS A KEY" / "PRESS A BUTTON" in SONAR_PALE, with a SONAR edge pulsing at 1.2 Hz (static under Reduce motion).
  - Rejected: a WARNING_RED edge until cleared. The inline copy is unchanged.
- **Other:**
  - 4 px scrollbar: TEXT_LO 25% track and a SONAR thumb.
  - Compact 48 px buttons (Open Songs Folder, Add Folder, Remove Folder, Re-run Calibration, Back).
  - The screen is an effect node: Low effects rebuilds the panel styles without glow.
  - settings_screen.gd left PENDING_MIGRATION, so the list is now empty. settings_screen, step_slider and rebind_cell use no legacy aliases (guarded by a test).

Gaps fixed (I re-ran g and a afterwards):
1. **Settings rows were 120 px apart, not 56.** The theme gives every MarginContainer 32 px margins, so the hidden message containers added 64 px under each row. Indents now zero their other margins (`_indent`).
2. **"(Not active yet)" rendered one letter per line,** because it was an autowrap label with no width. Inline hints no longer wrap.
3. **The panels ran to x 1868 instead of 1856.** The one-line Low effects hint (about 1213 px) widened the scroll content past its rect. Row hints now have a fixed width up to the value column (they wrap if too long), and the panels end at 1856.
4. **The re-calibration note overflowed the device panel** (by +2 px letter spacing). It now uses plain Share Tech Mono and fits inside 592 px.
5. **The audio step had an empty value slot while measuring.** It now shows a dim "-- MS" placeholder, and the result returns to SONAR.
6. **The summary was bare.** It now shows a "CURRENTLY SAVED AUDIO … · VISUAL …" line when an earlier calibration exists.
7. **The audio and visual steps were bare.** The TAPS grid and the CONTROLS panel fill the space right of the stage.

Accepted as-is, with reasons:
- **The audio-test background is plain ABYSS_900 while taps are recorded.** This is the T-02.2-41 mitigation (see the decisions above). The backdrop returns for the result and every other step.
- **The focus marker is caught mid-glide in a_02 and a_06,** where it overlaps Retry Test. Focus jumps from Skip (x 1536) to Accept (x 64) on the result, and at about 15 fps under xvfb the 120 ms glide is still running when the harness takes the shot. On the PC it finishes in under 0.12 s. Accept Offset has focus (the harness check passes).
- **The overlay over pause shows faint HUD numbers through the 85% shade.** These are the UI-SPEC 9.1 / plan values, the same as pause.
- **The right half of the Controls table (x 860..1840) is empty.** It is a two-column binding table. Stretching the cells would break the 280 px cell size the tests and harness rely on.
- **"Extra library folders" is empty when there are no folders.** This is existing behaviour; no new empty-state copy was added.
- **Content scrolls under the fixed header with a hard cut at y 136.** There is no fade mask. This is a possible polish item for plan 24.
