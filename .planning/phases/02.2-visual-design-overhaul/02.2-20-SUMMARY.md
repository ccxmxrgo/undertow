# Phase 02.2 Plan 20: Pause, IMPLOSION, dialogs and the intro rig boot Summary

Pause, IMPLOSION and the confirm dialog now use the design system: glass or danger panels with brackets, UiKit buttons and one focus marker per screen, over opaque-enough abyss backdrops, with behaviour unchanged. IMPLOSION adds a red vignette, six static cracks, a glowing red title with a 120 ms shake and a song progress row. The intro's grey room is gone. The FULL intro now opens with a rig boot (sonar pings and a typed rig readout under the closing lens) on the unchanged IntroTimeline, and the count numerals use Oxanium at the Cinematic 176 size.

Gaps fixed (I re-ran the scenarios afterwards):
1. **Pause run line read "Hand chart ·  · 16%".** The fixture chart has no difficulty name. Empty parts are now dropped, a test was added, and the line now reads "Hand chart · 16%".
2. **The pause panel showed through the dialog.** Its button labels ("Restart Dive", "Settings") were legible through the translucent glass behind the dialog body. The dialog now has an opaque abyss backing.
3. **The lens bridge cut the rig readout.** The mask's dark centre bar darkened "DIVE RIG" while the lens closed. The readout is now drawn above the mask, as a readout inside the goggles.
4. **The rig boot looked bare and the goggles cue was lost.** With only a near-black backlight, the closing lens had nothing visible to cover. I added faint static scope rings and a gapped crosshair, and raised the backlight peak from 0.30 to 0.42. In the offline render the lens lobes now show.

Accepted as-is, with reasons:
- **The harness's 1.0 s "lens focus" frame is black.** Under xvfb at about 20 fps, the shot lands in the BLACK stage (1.10..1.25 s). The offline render at exactly 1.0 s shows the rig boot inside the lens. This is an environment issue, logged in deferred-items.
- **The "DIVE" numeral covers notes at the horizon for 0.6 s.** This is the existing 01.2 cinematic behaviour, and only the font changed.
- **Pause has empty space between Back to Menu (bottom 696) and the hint (752).** These are the UI-SPEC 9.1 coordinates.
- **The IMPLOSION cracks are thin, unbranched lines.** The spec asks for 6 jagged polylines of 2 px at 35%, and I kept them subtle so they do not compete with the panel.
- **Settings behind the Reset Controls dialog still has the old look.** Settings is restyled in plan 21.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The progress would read 0% on IMPLOSION**
- **Found during:** Task 1
- **Issue:** `_on_failed` stops the conductor before it builds the fail screen.
- **Fix:** `progress_pct()` is read first.
- **Commit:** b969113

**2. [Rule 1 - Bug] The pause focus marker would draw over the confirm dialog**
- **Found during:** Task 1
- **Issue:** The marker is `top_level` with z 10, so it would draw above the dialog's dim.
- **Fix:** The marker is suspended while a dialog is open.
- **Commit:** b969113

**3. [Rule 3 - Blocking] The project rule bans the FULL_RECT preset**
- **Found during:** Task 1
- **Issue:** test_review_fixes forbids `set_anchors_and_offsets_preset(PRESET_FULL_RECT)`.
- **Fix:** The code uses `UiLayout.fill_rect` instead.
- **Commit:** b969113

**4. [Visual review] Run line, dialog backing, rig readout above the mask, scope layer**
- See the Visual review section above.
- **Commit:** 8e25dee

**5. [Interpretation] The test file layout differs slightly from the plan**
- The rig-boot tests are in a new file, tests/test_intro_rig_boot.gd, so that test_intro_flow.gd and test_intro_timeline.gd stay unchanged as the plan requires.
- `room_glow_texture()` is kept as the backlight for the same reason.

**6. [Interpretation] Screenshot names**

**7. [Copy] Dialog copy unchanged**
