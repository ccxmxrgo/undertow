- **MatchSim time walk.** `MatchSim._begin(t)` sets `_now = t` (match_sim.gd:438). Feeding it an earlier t than already processed moves time backwards, and that is why the queue exists.
- **Duel queries.** `MatchSim.duel_active()` returns the running solo index or -1. `duel_live(seat)` returns the live % or -1.0.
- **Approach margin.** `MatchSim.set_approach(seat, s)` exists after 04-02. HostInputQueue must call it with the margin-adjusted value, never the raw one, for every seat including the host's own.
- **Wire format.** NetProtocol (04-01) defines IN_* kinds, IN_ARITY and the item wire shape `[kind, t, seq, ...args]`. Its summary lists the final tables.
- **Channels.** EventChannel has `signal received(e)`, `send(e)` and `update(t)`.
- **Host event extras.** Events emitted by the queue itself (DUEL_LIVE, PLAYER_LEFT) go through the same channel as MatchSim's events and are appended to the queue's `extra_log`. The host's full broadcast log is `sim.event_log` merged with `extra_log` in emission order. Keep one `broadcast_log` in NetHostChannel; it is the single source of truth for "what clients received".
- **Leak rule.** Use method callables, not lambdas, for long-lived signal connections (CR-02).

  <behavior>
    - **Construction.** `HostInputQueue.new(sim: MatchSim, channel: EventChannel, d_s: float)` sets `players = sim.players`.
    - **Local inputs.** Calling the Referee input methods for the host's own seat queues items with an auto-incremented seq. request_fire returns Referee.FIRE_REMOTE.
    - **Network inputs.** `push_item(seat, item: Array)` queues a validated network item for that seat. The seat always comes from the caller, never from the item.
    - **pump(host_song_time):**
      - Sets horizon = host_song_time - D.
      - Releases every item with t <= horizon, sorted by (t, seat, seq) with an explicit comparator.
      - An item with t < released_t is applied at released_t, and `late_inputs` is incremented.
      - Calls `sim.update(horizon)`, then sets released_t = max(released_t, horizon).
      - Items with t > host_song_time + FUTURE_INPUT_S are dropped on push, and `rejected_future` is incremented.
    - **Determinism.**
      - The same scripted inputs from 3 seats give an identical sim.event_log whether pushed in order or in shuffled arrival order, as long as every item arrives before the horizon passes it.
      - It also matches feeding MatchSim directly in sorted order (the offline reference).
    - **Late input.** An item arriving after the horizon passed its t is clamped. The event t values in sim.event_log stay non-decreasing.
    - **drop_seat(seat, reason):**
      - Removes that seat's queued items.
      - Calls sim.on_failed(seat, released_t), so MatchSim emits IMPLODED.
      - Then emits GameEvent.PLAYER_LEFT {seat, reason} at released_t through the channel, after the IMPLODED.
      - A second drop of the same seat is a no-op.
    - **Approach margin.** `set_net_margin(seat, margin_s)` plus `set_approach(seat, s)` stores sim.players[seat].approach_s = s + min(margin, 0.3). Changing the margin re-applies it to the last reported s. `margin_for(d_s, rtt_p90_s)` is a static function returning min(d_s + rtt_p90_s/2 + 0.033, 0.3).
    - **DUEL_LIVE.**
      - While sim.duel_active() != -1, pump emits DUEL_LIVE {solo, pct: {seat: pct >= 0}} at most once per whole beat of the horizon (use BeatClock with the chart tempo map, as MatchSim does).
      - It never emits outside a duel and never twice in the same beat.
      - duel_live(seat) returns the last emitted pct for that seat, else -1.0.
    - **Debug stats.** `debug_stats()` returns {late_inputs, rejected_future, pending, released_t}.
    - **update(t) is a no-op.** The Referee `update(t)` override does nothing on HostInputQueue: only `pump(host_song_time)` advances MatchSim. This matters because SubRig and the controller call `sim.update(t)` with the live song time, which would bypass the horizon. Test: queue an item, call `update(t)` far past it, and assert sim.event_log and released_t are unchanged until pump().

| client inputs -> HostInputQueue | items have passed NetCodec. Seat is bound by the session from the sender id |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-13 | Spoofing | input for another seat | mitigate | push_item takes the seat as a parameter from the session; no seat field is read from items. RemoteReferee ignores foreign seats |
| T-04-14 | Tampering | far-future or past times poisoning the time walk | mitigate | future bound (2 s) drop plus the late clamp to released_t. The sim never goes backwards |
