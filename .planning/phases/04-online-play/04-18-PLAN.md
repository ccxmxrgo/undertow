     - Forward UDP 47474 (or your chosen port) to the host PC's LAN address, and give friends your public IP.
     - It does not work behind CGNAT (when the router's WAN address is 100.64.x.x or 10.x).
     - Traffic is not encrypted on this path. Tailscale and ZeroTier encrypt.
   - **Windows Firewall:** click Allow (Private networks) the first time you host. If you clicked Cancel: Windows Security > Firewall & network protection > Allow an app through firewall > UNDERTOW > Private.
   - **Changing the port:** use the Port field or Settings > ONLINE. Everyone must use the same number.
   - **Troubleshooting:** a table from each in-game error title to its fix (NO ANSWER, ADDRESS NOT FOUND, DIFFERENT VERSIONS, LOBBY FULL, MATCH IN PROGRESS, CONNECTION LOST, HOST LEFT, NO HOST SIGNAL, high-latency ping in red, "Your copy of this song differs").
   - **What crosses the network:** inputs and game events only, never files. There are no accounts in the game and no servers.
   - **Torpedo flight:** 2 beats is safe for the internet; 1 beat is for the same room.
   - **Reporting problems:** press F3 in a debug build, or note the PING in the lobby.
