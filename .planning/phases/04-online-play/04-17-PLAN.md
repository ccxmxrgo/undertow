**NetAutotest** (class_name, extends Node; added as a child of NetSession only when `--net-autotest=` is present). Its header documents the args:
- `--net-autotest=host|client`
- `--net-address=<ip>` (client; default 127.0.0.1)
- `--net-port=<n>` (default 47474)
- `--net-players=<2..4>` (host waits for this many)
- `--net-seconds=<n>` (max_song_s; default 30)
- `--net-diff=<easy|medium|hard|expert>` (default easy)
- `--net-report=<path>`: must be absolute or inside the project's build/net_smoke, and must end in .json; reject anything else.
- `--net-name=<NAME>` (defaults HOST, C1, C2, C3)
- `--net-timeout=<s>` (overall watchdog; default 120)
- `--mute`

Parse with a pure `static func parse_args(args: PackedStringArray) -> Dictionary` with validation, which the tests cover.

Flow:
- **Host:** host(port), then wait until the roster has net-players. Pick the first library entry that has net-diff, preferring bundled songs, and call host_set_song with its key. Wait for start_gate().ok, then `start_match({"max_song_s": seconds, "autoplay": true})`.
- **Client:** join(address, port). When its song status is ok, set_ready(true).
- **Both:** on match_loading, build the chart and change scene to gameplay (as the lobby does). Results come from the session signals/state. Then write the report and quit after 1.5 s. On the host, wait 2 s after host_send_results so clients receive RESULTS.
- **Overall timeout:** write a report with "error": "timeout" and quit with exit code 3.

Report JSON keys:
- role, seat, name, version (NetProtocol.game_version())
- start_unix_ms (from debug_stats)
- host_log_sha (host): SHA-256 of `var_to_str` of the host channel broadcast_log
- received_sha (clients): the same over the received_log
- events (count), late_inputs, landed_late_max_ms, skew_ms
- results_rows (array of {seat, name, left})
- left_seats (host: seats with PLAYER_LEFT)
- error (empty when ok)

Add `static func compare_reports(reports: Array, opts: Dictionary) -> Dictionary` returning {ok, lines: Array[String]}. This is the same logic net_smoke.ps1 applies, so it can be unit tested. Rules:
- every report has no error and the same version
- each client received_sha == host host_log_sha
- the start_unix_ms spread is <= 20 ms
- the host late_inputs == 0
- the results have N rows
- for opts.dropped_seat: the host's results row for that seat has left true, and the dropped client's report is missing or partial and is ignored

**NetSession hook:**
- In `_ready()`, if `--net-autotest=` is present, add a NetAutotest child.
- Record start_unix_ms in lead_in_for_start and add it to debug_stats.
- Expose the broadcast/received logs to NetAutotest through the bound match objects. Do not add new network messages.

tests/test_net_autotest.gd covers:
- parse_args: valid args, a rejected report path ("../x.json", "C:/Windows/x.txt"), an out-of-range players count and the defaults.
- compare_reports: an all-match PASS; one client digest mismatch FAILs; a 35 ms start spread FAILs; late_inputs 2 FAILs; the drop scenario PASSes with left true and FAILs with left false.
