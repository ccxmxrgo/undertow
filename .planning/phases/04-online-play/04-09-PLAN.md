Create `NetMatchHarness` (class_name, extends RefCounted). The header documents its opts and contract: "virtual song time; no nodes; NetCodec on every hop; same construction as the online VersusController backends".

opts (each read with `opts.get(key, default)` and clamped):
- `clients` 1..3
- `seed`
- `flight_beats` 1..2 (sets cfg.torpedo_travel_beats)
- `d_s` (horizon D, default 0.08)
- `latency_s`, `jitter_s`, `loss` (the defaults apply to every link)
- `links: {seat: {latency_s, jitter_s, loss}}`
- `fire_every_beats` (0 = off)
- `fire_from_beat`
- `drop_seat` and `drop_at_s`
- `end_t` (default: the chart end or 60 s)
- `fps` (default 120)
- `tick_s` (MatchHarness.TICK_S)

Construction:
- The roster is seats 0..clients with callsigns "HOST", "C1" and so on.
- The host side is MatchSim(chart, cfg, jcfg, players, host_channel, seed), HostInputQueue(sim, host_channel, d_s), and SubRig(0) on the queue with an _AutoActor.
- Each client gets its own players copy (fresh PlayerState per seat), a NetClientChannel(local_seat, now_fn, ctx), a RemoteReferee(seat, players, send_fn) bound to its channel, and SubRig(seat) on the RemoteReferee with an _AutoActor.
- Each rig sets approach_s = 1.5. The SubRig setter sends APPROACH through the referee. The host queue applies `margin_for(d_s, link_rtt_p90)` per seat via set_net_margin; for the harness the link RTT p90 is 2 × (latency + jitter).

Step loop (`step(t)`, fixed dt = 1/fps):
1. Run every actor due up to t in global order (as in advance_to).
2. Run the scripted fires.
3. Each RemoteReferee calls flush(), and the hub carries the messages.
4. hub.advance(t).
5. The host queue calls pump(t).
6. The host channel's take_batches go to the hub.
7. hub.advance(t) again, then the clients receive.
8. Apply the drop when due: hub.drop_peer(client), then the host calls queue.drop_seat(seat, "disconnected") at the moment peer_left fires, and host_channel.remove_peer.

`finish()`: release everything with pump(end_t + d_s + 1.0), then sim.finish(end_t) and a final broadcast.

`result()` returns:
- `host_log`: the host channel broadcast_log, deep-copied
- `client_logs` {seat: received_log}
- `late_inputs`
- `standings`
- `telegraph`: per landed torpedo {target, launch_t, arrive_t, target_receipt_t}, where target_receipt_t is the target client's song time when its channel emitted the TORPEDO_LAUNCH
- `overlay`: per LANDED of Ghost Notes/Depth Charge on a client {target, receipt_t, active_start, approach_local}
- `duel_live_events`

Add `static func run(chart, opts) -> Dictionary`.
