<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| zip file -> extracted files | Untrusted archive paths and sizes cross here |
| song folder / extra library folder -> scanner | Arbitrary directory tree incl. symlinks/junctions, huge counts |
| user://song_cache.json -> SongCache | User-writable JSON |
| audio bytes -> engine decoders | Malformed audio |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Tampering | ZipExtractor | mitigate | safe_rel rejects empty/absolute/drive/`..`/backslash-escape; allow-listed extensions; writes only under hashed dest dir; tests with `../evil.txt`, `C:/x.chart` |
| T-02-07 | Denial of Service | ZipExtractor | mitigate | <= 4,000 entries, <= 2 GiB cumulative, <= 512 MiB per entry, runs on worker thread |
| T-02-08 | Denial of Service | SongScanner walk | mitigate | depth cap 6, 20,000 entries cap, visited-set against junction loops, cancel flag checked between songs |
| T-02-09 | Tampering | SongCache JSON | mitigate | version check, type validation per field, size cap, discard on any problem; never evaluated, no ResourceLoader |
| T-02-10 | Elevation of Privilege | open_songs_folder | mitigate | OS.shell_show_in_file_manager on a globalized, just-created directory only; no OS.execute |
| T-02-11 | Tampering | extra library folders | mitigate | scanned read-only; test asserts no writes; zips extracted into user://song_cache only |
| T-02-12 | Denial of Service | audio decode | accept | Engine decoders on user's own files; Opus/unknown rejected by header before decode; failure becomes ERR_AUDIO_BAD |
