## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] F11 / Fullscreen OFF did nothing on the real window**
- **Found during:** Task 3 (polish scenario, first run)
- **Issue:** With `window/size/mode=3`, `window_set_mode(WINDOWED)` reports EXCLUSIVE_FULLSCREEN (4) and ignores the 1600x900 size. A minimal standalone Godot 4.7.2 project shows the same thing. Starting windowed, the toggle works.
- **Fix:** project.godot now uses `mode=0` with a 1600x900 window override. The existing `Settings.apply_window()` goes fullscreen at boot. Added regression test `test_project_creates_window_windowed_1600x900`.
- **Files:** project.godot, tests/test_settings.gd. **Commit:** a86457e

**2. [Rule 3 - Blocking] Harness menu navigation off by one after Practice Dive was added**
- Autoplay now takes 2 Downs, Calibrate 3 and Settings 4 (start_dive_from_menu, sc_a, sc_g). Commit a3e42ff.

**3. [Rule 2 - Critical] Records isolation for all scenarios + stall watchdog**
- `isolate_settings` now points `ScoreStore.default_path` at `user://playtest_scores.cfg`. The polish scenario uses `user://polish_scores.cfg`. Both are deleted and the real path is restored in `_finish`.
- run_all.ps1 runs each scenario through Start-Process with a hard limit (300 s, or 600 s for drift) and kills the whole Godot process tree with `taskkill /T` on a stall. Per-scenario stdout goes to `build/playtest/<s>_stdout.txt`.

**4. Minor**
