<decisions>
## Implementation Decisions

### Controls (POL-01)
- **D-01:** The default keyboard lanes become **1 2 3 4** (top-row number keys; use physical keycodes so they work on any layout), replacing D F J K. Gamepad defaults are unchanged. Fire, Target-cycle and Pause keep their defaults (Space, H, Esc). Existing saved bindings in a player's settings.cfg are NOT overwritten; only defaults and "Reset Controls" change. Supersedes Phase 1 D-18 for lane keys.

### Look: neon lanes + cyberpunk goggles (POL-02)
- **D-02:** Each lane gets its own color, and the shape is kept. Lane 1 ◆ cyan `#22D3EE`, lane 2 ● amber `#FBBF24`, lane 3 ▲ magenta `#F472B6`, lane 4 ■ lime `#A3E635`. The HUD, lane borders and the hull line stay sonar-green. Miss red `#FF4A3D` stays reserved for damage and misses. Per-lane colors also apply to sustain tails, hit flashes and Perfect rings.
- **D-03:** **Art direction from the user: "cyberpunk, like you're inside one of those goggles."** Phase 1.1 delivers a lightweight visor frame around the highway and HUD:
  - dark vignette edges and a subtle lens curve or rounded mask
  - thin HUD bracket corners and a few small readouts at the frame edge
  - a faint scanline overlay
  Keep it cheap (one canvas_item shader or `_draw`, Compatibility renderer) with a low-effects toggle. The full CRT/visor suite stays in Phase 5. Record the direction in UI-SPEC.

### Readability: hit receptors (POL-03)
- **D-04:** Each lane gets a hit-marker receptor on the hull line: an outline of that lane's shape in the lane color, at the exact hit position. It pulses on press.
- **D-05:** Approaching notes are drawn at reduced brightness (about 55%). They switch to full brightness and glow **only once the note is inside the Good window** (|t| ≤ good window). This fixes "highlighted but not ready". Note **centers** mark the hit time. Check that the shape size and receptor make this obvious.

### Window (POL-04)
- **D-06:** The game opens **borderless fullscreen** by default. F11 toggles fullscreen and windowed. A Settings switch "Fullscreen" mirrors it. The choice is saved in settings.cfg. Windowed mode opens at 1600×900, centered. Rendering stays a 1920×1080 base with canvas_items stretch.

### Replay motivation (POL-05, POL-06)
- **D-07:** **Best score per song** is kept in `user://scores.cfg` (separate from settings), keyed by chart id/hash, storing best depth, best accuracy %, max combo and date.
  - The results screen shows "NEW RECORD" when the score is beaten, plus the previous best.
  - The main menu or song entry shows the best depth.
  - Autoplay and No-Fail runs **never** count toward records.
  - Parse the file defensively (same rules as settings.cfg), with an atomic save.
- **D-08:** **Note streak** is made prominent:
  - A large streak counter above the highway, near the hull line, that grows and glows with the streak.
  - Milestone popups at 10, 25, 50, 100, then every 100 ("25 STREAK"). They use lane-neutral accent color and respect reduce-motion.
  - The existing HUD Perfect-streak and combo stay.

### Practice (POL-07)
- **D-09:** Difficulty stays as it is (user decision). The main menu gets a visible **"Practice Dive (No-Fail)"** entry directly under "Start Dive", which starts the run with No-Fail on. The results flag "NO-FAIL USED" stays, and practice runs never set records.

### Ship (v0.2)
- **D-10:** End of phase:
  - Re-export.
  - Build `build/dist/UNDERTOW-playtest-v0.2.zip`, with the README updated: keys 1 2 3 4, fullscreen/F11, practice, high scores, and the same feedback questions plus "is it easier to tell notes apart?" and "do notes look ready at the right moment?".
  - Keep the zip under 30 MB if possible, so it can be sent to the phone app. Consider a release export (no console exe in the zip, or the console exe only), or stripping debug symbols.

### Claude's Discretion
- Exact visor-frame look, streak counter placement, popup animation, scores.cfg schema details, how the menu shows the best score.

- 188 unit tests, plus a windowed playtest harness with screenshots for visual verification.

## Amendments (user answers after research, 2026-10-08)

- **D-11 (keys migration):** a one-time migration is approved. If a saved settings.cfg has no `bindings_version` marker AND its four lane keys are exactly D/F/J/K (the old defaults), switch them to 1/2/3/4 and write the marker. Custom bindings are never touched. This is a narrow exception to D-01's "don't overwrite".
- **D-12 (packaging):** ship a **.zip only** (`UNDERTOW-playtest-v0.2.zip`). It is fine that it is over 30 MB; the user shares it from the PC. Use a release export if it is not larger. The research measured the release template as bigger, so keep whichever export is smaller and still works.
- **D-13 (streak):** **both counters, combo big.** Combo (Perfect+Good in a row) gets the large counter and the milestone popups at 10/25/50/100/every 100. The Perfect streak stays visible but smaller. It is the torpedo counter in Phase 3.
- **D-14 (failed runs):** the IMPLOSION screen shows **this run's** depth reached and max combo, plus the saved best for comparison. Failed dives do **not** update saved records; only finished, eligible dives (no autoplay, no No-Fail or practice) can set records.
- **Planning note (2026-10-08):** NOTE_DIM is 0.60 rather than "about 55%" (Claude's discretion, per the UI-SPEC magenta contrast). The visor brightness check compares the same pixel with low_effects on and off.
